Not fixed, accepted with reasons:
- **Migrating off `keyboard`** (K-07): it's the only maintained-enough cross-key hook that's pure-pip on Windows today, and replacing it is a rewrite. Pinned and documented; revisit if it breaks.
- **Code signing** (K-16): there's no certificate for a personal repo. The source is short and readable instead, and the README warns about EDR.
