# KRYPTONITE — RED TEAM REPORT
Target: Voice Anywhere v0.1.0 (commit cfa1790)
Date: 2026-11-05
Verdict: DO NOT SHIP (as configured) — one critical default-key defect makes the tool fire on ordinary Left Ctrl. Fix K-01 and it moves to SHIP WITH FIXES.

Method: read every script and doc; `py_compile` clean; 14/14 unit tests pass on Python 3.14.7; runtime imports verified in the installed venv; the `keyboard` scancode behaviour below was verified empirically, not assumed. I did not run install.ps1, did not touch the running process, made no repo changes except this report.

## Claims vs reality
- "Audio is captured only while the key is held, kept in memory and never written to disk." — **PARTLY**. True for mic capture (`record_while_held` buffers `indata.copy()` in RAM, `voice_anywhere.py:434-449`). But `--self-test` writes a TTS WAV to temp (`:372-388`). Qualify the wording (K-15).
- "No audio or text is sent anywhere." — **TRUE**. Only network call is the one-time HF model download (`load_model`, `:319-329`); no telemetry anywhere in the code.
- "The always-on log records timings and lengths only, never what you said." — **TRUE for `--background`**, **FALSE for foreground `--log`** (logs full transcripts, K-04). README line 59 directly contradicts the claim (K-05).
- "It never presses Enter for you unless you ask it to." — **TRUE**. `--auto-send` defaults False (`:59-60`, verified by test). Caveat: focus-change risk (K-02).
- "Only one copy ever runs" (background). — **TRUE**. Named mutex `Local\VoiceAnywhereSingleInstance` (`:572-579`).
- "On Windows 11 the knot pins itself to the visible taskbar from the second start." — **TRUE**. Writes `IsPromoted` (`:224-246`); effective next start, as documented.
- "Transcript is placed on the clipboard (and stays there unless --restore-clipboard)." — **TRUE** (`:455-466`).
- "Private by design / transcription fully local." — **TRUE** for the transcription path; undermined operationally only by K-01 (mic opens on Left Ctrl) and K-04/K-06 (disk/clipboard residue).

## What holds up
- **Pure logic is genuinely well-factored and tested.** Parser, text cleaning, word-overlap, chime synthesis, overlay geometry and knot rendering are split out and covered by 14 tests that pass on Python 3.14.7. Scripts `py_compile` cleanly and all runtime deps import in the venv.
- **The core privacy promise is real**: transcription is local; the only egress is the model download. No hidden telemetry.
- **Graceful degradation is done right**: tray, overlay, chime and indicators each disable themselves on missing deps without taking the app down (`Tray.start`, `Overlay._run`, `App.chime`).
- **Solid plumbing**: single-instance mutex, log rotation at 1 MB with one `.old` copy, click-through/no-activate/topmost overlay flags, per-monitor-v2 DPI awareness, premultiplied-alpha blit — all correct.
- **The busy-lock and auto-repeat guard** (`on_talk_key` + `busy.acquire(blocking=False)`) correctly prevent overlapping recordings.

Bottom line: the engineering craft is above average for an afternoon build, but K-01 means that out of the box the tool hijacks the most-used key on the keyboard and can inject text during normal work. That is a shipping blocker, not a polish item. Fix K-01 (and ideally K-02/K-03) before anyone else installs it.
